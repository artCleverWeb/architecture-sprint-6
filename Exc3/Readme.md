# Проблемы:
1. Синхронное взаимодействие между сервисами ins-product-aggregator, core-app и ins-comp-settlement через REST API
2. Возможна не консистентность данных в сервисах core-app и ins-comp-settlement из-за определенного графика обновления данных в сервисах
3. Задержки и ошибки при взаимодействии с API страховых компаний

# Риски:
1. Риск каскадных ошибок при увеличении нагрузки на сервис ins-product-aggregator или его недоступности
2. При увеличении кол-ва API сервисов страховых компаний кратно возрастает время ответа сервиса ins-product-aggregator
3. Сложности в маштабируемости системы, т.к. взаимодействие сервисов строится на синхронных запросах.

# Решение:
Переход на Event-Driven архитектуру и внедрение асинхронного взаимодействия между сервисами ins-product-aggregator, core-app и ins-comp-settlement, что позволит утсранить текущие проблемы и повысить масштабируемость системы
